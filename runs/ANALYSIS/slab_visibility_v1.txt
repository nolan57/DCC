[3] Direct consequence of opacity: what you see is the 'boundary', not the 'object'
  For an opaque medium, reflection imaging satisfies: I(x,y) = R_surface(x,y) * L_env(x,y)
  That is, the pixel value is determined only by the **outer-surface reflectivity** and the **ambient light**, independent of internal structure.
  => Whether the inside is brain, bone, liver, or empty, from the front it is always the same skin surface.

  [ARGUMENT] S3_reflectance_sees_boundary_only  PASS   The 3D structure of the 7 cm slab is compressed in the reflection channel into a boundary function R(x,y), with all internal degrees of freedom lost

[4] So what does the 'boundary' look like: a skin sheet + wrinkles
  Boundary = adult skin, area 1.8 m^2, while the projected footprint is only 1.0 m^2
  Area ratio = 1.80: the skin must **fold** to fit into 1.0 m^2
  If the wrinkle wavelength lam_w = 2 mm, then the amplitude a = 0.81 mm (a/lam = 0.40)
  Number of wrinkle features ≈ (1000mm/2mm)^2 = 2.50e+05
  => The surface is not a 'perfect plane' but a **crumpled leather**: it has 2e+05 millimeter-scale light/dark wrinkles.
     This is the only visible texture in this branch, and it provides only **monochrome light/dark**, no color differentiation.

  Composition comparison (determining 'whether there is color'):
     Skin  : two chromophores — melanin/hemoglobin — with a narrow hue range (brown-pink-red)
     Organs: liver brown, spleen purple, fat yellow, muscle red — **huge differences, but all internal**
     => The color information exists, but is blocked by opacity at more than 1 mm beneath the skin.

[5] Resolution ≠ information (this is the core of the 'white wall' verdict)
  Resolution: how many independent pixels can be distinguished geometrically
  Information: whether the values of these pixels differ from each other (entropy)

  Observation method         Number of resolvable units Fraction with different values
  --------------------------------------------------------------
  Human eye @25cm (0.073mm)  1.88e+08       ~1 (only wrinkle light/dark)
  Macro camera (10μm)        1.00e+10       ~1 (same as above)
  Optical microscope (1μm)   1.00e+12       ~1 (surface still uniform)
  X-ray CT (0.5mm)           5.60e+08       ~10^2 (has 3D structure)

  The human eye can indeed resolve 1.9e8 points over 1 m^2 — but if the statistical distribution
  of these 1.9e8 points differs from its own mean by only a few percent, then **extractable information ≈ log2(number of distinguishable classes) ≈ 1~2 bit**.
  High resolution + low contrast = a high-pixel-count solid-color image. This is the literal meaning of 'white wall'.

  [ARGUMENT] S5_resolution_is_not_information   PASS   1.9e8 pixels × 1~2 bit = information content on the same order as a blank A4 sheet

      This is structure accessible to visible light, but it is 'an edge', not 'a face'.

  (c) Chemical/fluorescence staining
      Converts invisible compositional differences into visible color differences; the cost is introducing exogenous labels.

[7] Conclusion
  'Rich in detail' and 'looks like a white wall' do not contradict each other; they refer to two different things:
    · Rich in detail: the object has ~1e11 cell-scale structural differences inside — true
    · Looks like a white wall: in reflected visible light, the output is a nearly uniform monochrome field — also true
  The bridge between the two is 'opacity': it blocks the 3D structure beyond 1 mm, releasing only a layer of skin.

  => The correct statement is not 'this branch has no detail', but:
     **This branch has extremely rich structure, but the reflected-light channel cannot read it.**
     To read it, one must switch to transmission (X-ray/CT), cross-section (side view), or staining (exogenous labels).

     Not 'little information', but 'information invisible in reflected light'. This is a channel problem, not a stock problem.
