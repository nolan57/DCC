[E] THE STEELMAN: WHAT A SPACE-FILLING sigma WOULD ACTUALLY BUY
====================================================================================================
  Ignore for a moment that S3 is inadmissible and ask the useful question: if the deposit's array is
  read as an image, which ordering of layers onto sites is most legible? Implement three candidates
  and measure two quantities on an S x S square:

    rho        = median|dn| between VERTICALLY adjacent sites / same for HORIZONTALLY adjacent sites
                 (anisotropy: how unequal the z-step is along the two array axes)
    contiguity = fraction of the |dn| = 1 layer pairs that land on 4-adjacent sites

  candidate sigma            rho      contiguity  median |dn| all adj  p90 |dn| all adj  max |dn| vert
  -------------------------  -------  ----------  -------------------  ----------------  -------------
  raster (n = r*S + c)       256.000  0.9961      128.5                256               256          
  Hilbert (order 8)          1.000    1.0000      1.0                  45                21845        
  spiral (centre-out rings)  1.500    0.9980      1.0                  907               1015         

   => P11 (raster rho = S exactly = 256): PASS  (rho = 256.000)
   => P12 (Hilbert rho <= 2): PASS  (rho = 1.000)
   => P13 (spiral rho <= 3): PASS  (rho = 1.500)
   => P14 (contiguity 1.000 for all three): FAIL  (raster 0.9961, Hilbert 1.0000, spiral 0.9980)

  Reading. None of the three is best at everything:

    raster  contiguity 0.9961  rho 256.0   — one array step along a row moves ONE layer
            (0.215 nm of body height); one step down a column moves 256
            (0.06 um). At the registered side that ratio is 90126:
            a vertical neighbour is 19.4 um away, a horizontal one 0.215 nm.
    Hilbert contiguity 1.0000  rho 1.0   — the only true Hamiltonian path of the three
    spiral  contiguity 0.9980  rho 1.5   — isotropic, but breaks at ring seams

  Contiguity was predicted to be a TIE (P14). It is not: contiguity separates the three, and Hilbert
  wins it outright at exactly 1.0000. The raster's 0.9961 loss is the row-end wrap, the spiral's
  0.9980 is the ring seam. So on the one property the submission's premise actually needs — that
  consecutive layers land on adjacent sites — the proposed algorithm is the unique winner, and the
  record's implicit order is not.

  Anisotropy, however, and the cost of the curve, measured rather than assumed:

    median |dn| over all adjacent pairs : raster 128.5   Hilbert 1.0   spiral 1.0
    p90    |dn| over all adjacent pairs : raster 256   Hilbert 45   spiral 907
    max    |dn| over adjacent pairs     : raster 256   Hilbert 21845   spiral 1015

  Hilbert does not trade one statistic for another: it beats the raster on the median, the 90th
  percentile and contiguity, and is isotropic. Its only loss is the single largest jump
  (21845 layers, where the curve passes near itself), which raster does not have because raster
  has no such passage. Raster keeps exactly one advantage: along a row it steps by precisely one
  layer, which no curve can match on both axes at once.

  So the submission's algorithmic instinct is CORRECT and its stated reason is not. A space-filling
  sigma is the better ordering for reading the deposit as an image, and the submission is the first
  text in this record to notice that the ordering was never chosen.
  That is a real merit, and it is a DISPLAY merit. It is also a merit the submission never states: it
  argues from 'information conservation', which all three satisfy equally.
