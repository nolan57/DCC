[3] P3 -- ME3 WITH A STATIC phi IS A MINIMUM-THICKNESS CRITERION
==============================================================================================
  With delta_E = C * lambda^k / t^k  (k > 0), the constraint delta_E <= d_max is EQUIVALENT to
      t >= t_min := lambda * (C / d_max)^(1/k)
  so the admissible set is UPWARD-CLOSED in thickness.  A flatness criterion must be
  DOWNWARD-closed.  The two cannot be the same criterion.

  delta_E,max  t_min (m)   real object at t = 1.540e-14 m
  -----------  ----------  ------------------------------
  0.01         2.0000e+00  FAIL                          
  1            2.0000e-01  FAIL                          
  100          2.0000e-02  FAIL                          
  1e+26        2.0000e-14  FAIL                          
  1.69e+26     1.5385e-14  PASS                          

  monotonicity: t1 < t2  =>  delta_E(t1) > delta_E(t2)  =>  (pass t1) implies (pass t2).
    t = 1e-15 m -> delta_E = 4.000e+28;   t = 1e-12 m -> delta_E = 4.000e+22
    upward-closed? True   => every object thicker than t_min passes, and thinner ones fail.

  The criterion therefore says: 'the object must be AT LEAST this thick.'  For a reduction to
  two dimensions, that is the opposite of the requirement.  It is a flatness prohibition.

  P3  CONFIRMED   static ME3 is algebraically a minimum-thickness criterion (upward-closed)
       measured: delta_E falls 1.0e+06x as t rises 1e+03x; closure is upward

[6] P8 -- THE SIGNED-DISTANCE READING ON A CYLINDER: delta_E = R/t EXACTLY
==============================================================================================
  phi = signed distance.  Then |grad phi| = 1 a.e. and the ratio is purely geometric:
    numerator   = Int d_z^2 over the surface with n_z != 0  = the two faces   = 2*pi*R^2
    denominator = Int (n_x^2 + n_y^2)                        = the rim        = 2*pi*R*t
    delta_E     = R/t

  discretised cylinder R = 8, t = 16 cells:
    measured delta_E = 0.3475     R/t = 0.5000     ratio = 0.695

  P8 was registered at 2% tolerance.  The gap is 30%.  The reason is structural, not numerical:
  for an L-infinity distance the gradient is supported on CONES inside the body, not on the
  surface, so the ratio counts volumes; and for the EUCLIDEAN signed distance it is worse:

    grad phi = n along every characteristic, so by coarea
      Int_V (d_z phi)^2 dV = Int_0^inf  Int_{phi=s} n_z^2 dA  ds
  which DIVERGES in s.  The Euclidean geometric reading is unbounded, and its value depends on
  how far the volume is truncated -- it is not a number attached to the object.

  So the geometric class is not 'R/t, i.e. ME2 restated'.  It is: L-infinity gives a
  volume-counting O(1) ratio with weak t-dependence (P7 measured k = 0.43), and Euclidean gives
  a divergent one.  Neither is a criterion, and neither is the aspect ratio.

  P8  REFUTED     signed-distance reading reproduces R/t to the registered 2%
       measured: measured 0.347 vs R/t 0.500 = -31%
