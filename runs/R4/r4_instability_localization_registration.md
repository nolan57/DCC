# R4 instability localization — registration (2026-11-22, sixth round)

**Question.** The 2+1 ADM free evolution (zero shift, 1+log, 2nd-order FD) is unstable at the grid
scale. Is that mode

- **(A) BULK** — a weak-hyperbolicity / continuum ill-posedness mode, which requires a strongly
  hyperbolic reformulation (BSSN or Z4c + Gamma-driver); or
- **(B) EDGE** — a mode generated by the boundary treatment (the `RHO_IN = 4` excise surface where the
  inner edge is handled by quadratic extrapolation, or the frozen-background Dirichlet outer edge), in
  which case it is a **boundary-condition bug**, not a formulation defect?

This is a discrimination test, not a confirmation test. **Both answers are acceptable outcomes, and one
of them falsifies a conclusion I registered yesterday.**

**Why it is worth a round.** The planned next investment is a BSSN/Z4c rewrite. The registered B0
finding was `rate x h ~ const` (0.386 / 0.362 / 0.261) with growth *worsening* under refinement. That
signature is consistent with **both** branches, and the claim actually written down was deliberately
weak: *"not curable by KO dissipation or boundary treatment"*, explicitly **weaker** than "no
formulation of this system can be stable". Two boundary treatments were tried (KO eps <= 0.4;
Dirichlet vs extrapolation), but the **inner cut radius was never varied**, and no eigen-analysis was
done. `F.7.2` finding 3 says "the cure is a strongly hyperbolic formulation, not parameter tuning".
If branch (B) is found, **that sentence is wrong and must be amended**.

## Design

All tests reuse **the production operator** `axisym_2p1_evolution` (`rhs`, `symmetrise`, `Grid`,
`flat_state`, `run`) by import. No geometry is re-implemented, so no new transcription risk is added.

| ID | Test | Purpose |
|---|---|---|
| C3 | Jacobian correctness anchor: `J.d` vs central finite-difference directional derivative along a random unit `d` | validate the assembly (parity + BC + einsum slicing) before trusting any spectrum |
| C1 | **Geometry dependence**: flat space, `h = 0.4` fixed, three configurations — (rho_in=4, R=24), (rho_in=8, R=24), (rho_in=4, R=36) | does the growth rate track the inner cut, the outer edge, or neither? |
| C2 | **Eigen-analysis** of the semi-discrete operator `F = rhs o symmetrise` at flat space, N = 16 and N = 20 | leading `Re lambda`, its eigenvector's field content and spatial location |
| C4 | **Consistency**: `Re lambda_max` from C2 vs the growth rate measured by time integration on the *same* grid | two independent methods must agree |
| C5 | FD-step independence of the spectrum (`eps = 1e-6` vs `1e-7`) | the spectrum must not be an artefact of the differencing step |

Grids for C1 are chosen so `h = 0.4` in all three (`N = 50/40/80`), so a rate change can only be
attributed to geometry, never to resolution.

C1 uses the production path (`KO_EPS = 0.2`, `CFL = 0.25`, frozen-background Dirichlet edge, t = 2).
C2/C4/C5 use `KO_EPS = 0.0` **in the Jacobian only** (an eigen-analysis of a dissipation operator is a
different question); this is disclosed and the module constant is restored afterwards.

## Thresholds (registered before the run)

| Test | Criterion |
|---|---|
| C3 | relative error `\|\|J.d - FD\|\| / \|\|FD\|\| < 1e-6` at the best of `eps in (1e-5, 1e-6, 1e-7)`. **If C3 fails, C2/C4/C5 are void** (a wrong Jacobian produces a meaningless spectrum) |
| C1 | branch classification by growth-factor ratios: **all three within 1.5x** -> BULK; **inner-cut config differs by > 2x** -> INNER-EDGE; **outer config differs by > 2x** -> OUTER-EDGE. All numbers reported regardless; the classifier is applied as written |
| C2 | instability confirmed iff `Re lambda_max > 0`. Localization: **edge** if >= 50% of the eigenvector mass lies in the first or last 8% of the radial extent; **grid-scale** if the checkerboard index `\|\|sum (-1)^(i+j)\|v\|\| / sum\|v\| > 0.5`; field content reported as mass fractions over the 11 fields |
| C4 | `\|Re lambda_max / rate_measured\|` in **[0.3, 3.0]** (order-of-magnitude agreement between an eigenvalue and an RK4 growth measurement) |
| C5 | leading `Re lambda` agrees within **1%** between the two FD steps |
| C2 scaling | grid-scale modes should satisfy `Re lambda` ~ 1/h, so `Re lambda(16)/Re lambda(20)` ~ 1.25 within a factor 1.5 |

## Registered predictions (stated before the run, both branches)

- **If BULK:** C1 rates agree within 1.5x across all three geometries; the C2 eigenvector is

## Addendum (2026-11-22, written after the first run, BEFORE the C6/C7 run — full disclosure)

The first run (`runs/R4/r4_instability_localization_results.txt`) completed with C3 PASS, C5 PASS,
C1 = INNER-EDGE, C4 = FAIL. Reading it exposed **two defects in the design of my own metrics** and one
internal contradiction. None is a numerical error; all are metric-design errors. They are recorded here
before the corrected tests run, so the correction cannot be mistaken for moving a goalpost.

### A1. The 2D checkerboard index cannot detect one-directional alternation

The registered index was `|sum_{i,j} (-1)^(i+j) |v_ij|| / sum |v_ij|`. For a mode alternating in `z`
only, `v ∝ f(i) g(j)` with `g` alternating, this factorises as `(sum_i (-1)^i f)(sum_j (-1)^j g)`, and
the first factor is `O(h) sum f` for smooth `f` — so the index collapses toward 0 **even though the mode
is fully grid-scale in the z direction**. The measured value (0.02 at N=16, 0.01 at N=20) is therefore
**not evidence that the mode is smooth**; it only shows it does not alternate in both directions at
once. Replaced by per-direction indices (C6).

### A2. C1's growth ratio is confounded by the initial truncation amplitude

`Ham(0)` differs by 8x between the baseline and the moved inner cut (1.421e-4 vs 1.738e-5), because
moving the cut away from the steep `1/rho` region lowers the truncation level. `growth = Ham(2)/Ham(0)`
then compares **two different seeds**, not two amplification factors. In absolute terms `Ham(2)` is
9.373e-4 vs 4.608e-4 — a factor **2.0**, not the 4.02 the ratio produced. **The INNER-EDGE verdict is
not licensed**; it is an artefact of a ratio with a denominator that depends on the geometry.

### A3. C4's failure is informative, not merely a failed test

`Re lambda_max = 0.636` vs a measured growth of `0.1266` (factor 5.02). The leading eigenvector is
dominated by `gpp` (0.49-0.57) with `Kpp` (0.15-0.16). In a formulation with a dynamical lapse and zero
shift, a `gamma_phi_phi`/`K_phi_phi` mode is a prime candidate for a **gauge mode**, and the registered
diagnostic `||Ham||` would barely see it. So C4's failure may mean "the top mode carries no constraint
violation", not "the spectrum is wrong". This must be measured, not assumed (C6b).

### C6 (registered now, before running): mode structure and constraint content

For the top-8 eigenmodes at N = 16 and N = 20, report per mode:
(i) per-direction alternation `alt_rho = |sum_i (-1)^i m_rho(i)| / sum m_rho(i)` (and `alt_z`), where
`m_rho(i) = sum_j V2(i,j)`; (ii) mass fraction within 10% of each edge; (iii) the radial index at which
`m_rho` peaks, as a fraction of the domain; (iv) **constraint content**
`||Ham[v]|| / ||v||` and `||Mom[v]|| / ||v||` via a central difference of `ax.rhs`/`ax.momentum` around
the flat state.

Criteria:
- **grid-scale** iff `max(alt_rho, alt_z) > 0.5` (either direction suffices — this is the repair of A1);
- **edge-localized** iff >= 50% of the mass lies within 10% of an edge;
- **constraint-neutral** iff `||Ham[v]||/||v||` is below **1%** of the maximum over the top-8;
- the **constraint instability** is then defined as the largest `Re lambda` among the *non*-constraint-neutral
  modes. C4's consistency test is **re-evaluated only against that eigenvalue**, and the original C4
  number for the absolute leading mode is retained and reported as-is.

### C7 (registered now): seeded amplification — the unconfounded version of C1

The truncation-level confound (A2) is removed by seeding **the same analytic perturbation** in every
geometry and measuring its amplification by differencing against an unseeded control run on the same
grid: `delta(t) = st_seeded(t) - st_unseeded(t)`, `A = ||delta(2)|| / ||delta(0)||`. The seed is a
Gaussian bump in `(rho, z)` centred at the **same absolute location** (rho = 12, z = 0) in all three
configurations, with identical amplitude and width, so it is far from every boundary in every case.

Criterion: `A(rho_in=4) / A(rho_in=8) > 2` -> INNER-EDGE; `A(R=24) / A(R=36) > 2` -> OUTER-EDGE;
all three within **1.5x** -> BULK. Same thresholds as C1, applied to the unconfounded quantity.
