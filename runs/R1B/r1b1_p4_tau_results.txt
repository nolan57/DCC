  The rate above is an average over a random (Poisson) array.  Two other arrangements are
  equally consistent with everything the state says, and both give a different answer:

  arrangement                  elastic channel                         tau_tr
  ---------------------------  --------------------------------------  ----------------
  mobile protons (fluid)       none: e-p scattering conserves the      INFINITE
                               total e+p momentum, so no charge
                               current is relaxed (COM accelerates)
  perfect proton lattice       none below the first reciprocal vector  INFINITE
                               (Bloch states): 2 k_F/G_min = 0.691 < 1
  disordered (Poisson) array   yes, the Born average above             2.004e-20 s

    impurity spacing d = 1/sqrt n = 31.50 fm ; G_min (triangular) = 0.23036 fm^-1 ;
    2 k_F = 0.15917 fm^-1 ; the lattice has no umklapp channel for these carriers.

  Both clean limits are PERFECT CONDUCTORS (a Drude delta at w = 0), not insulators.  So
  the ideal P2 level is exactly the tau = infinity case round 45 declared, and the finite
  number is a property of disorder alone.  The state carries neither a lattice nor disorder:
  Q-1 (localized) and Q-2 (disordered) are premises, and the answer is conditional on both.

  Consequence for S7: the mechanism is named, traced and unscanned, but its ACTIVITY is a
  structural premise.  S7 is PASS-ON-PREMISE, not PASS -- the criterion asks what fixes
  tau, and the honest answer is 'the impurity arrangement, which the model does not fix'.
  Refinement (iii), RQ-05, is where that premise would be earned or refused.
