PHASE 1 — delta_ov FOR THE mu_ov ESTIMATOR  (GD3: target = delta_ov / O6)
==============================================================================
  definition: delta_ov := sup over GRAPHS of mu_ov_est at declared (Delta_x, Delta_z_res; s_max)
  estimator: geometric -- the (max-min) of z over a column's lateral footprint is what a depth
  sampler sees; the column reads as double-valued iff that span >= Delta_z_res.
  pre-registered: P1a (delta_ov = 0 achievable), P1b (overlap iff s_max*Delta_x >= Delta_z_res),
  P1c (state-independence), P1d (delta_ov = 0 flips nothing)

         96     0.123698     0.123698     1.4e-17 
    (ii) direction factor -- a 1-D rise spans s_max*Delta_x; a rise along the cell DIAGONAL
         spans sqrt(2) times that. Measured: plane 0.9167, diag 1.2964, diag/plane = 1.4142
  CORRECTED STATEMENT. span_max = (1 - 1/C) * d * s_max * Delta_x with d in [1, sqrt(2)]
  (d = 1 for a one-directional rise, sqrt(2) along the diagonal). Registered form omitted
  both factors; it is recovered as C -> infinity on a 1-D ramp.
  => the edge is a BAND [s_max*Delta_x, sqrt(2)*s_max*Delta_x], not a line, and inside the
     band whether a given graph is flagged depends on its slope distribution.

[P1-5] DOES delta_ov MOVE ANYTHING?  (P1d, and what the only other value does)
  at Delta_z_res = 1.0e-04 m and Delta_x = 1.0e-04 m the resolvability edge is s_max = 1.00e+00,
  i.e. every surface with s_max <= 1 is resolvable, so the strict value delta_ov = 0 applies.
  state   span (m)      mu_ov    verdict @ d=0 verdict @ d=1
  sheet   1.5400e-14    0.0      PASS          PASS         
  stack   1.0780e-13    0.0      PASS          PASS         
  slab    7.0000e-02    1.0      FAIL          PASS         
  prediction P1d (delta_ov = 0 changes no verdict): CONFIRMED

  BUT the only other admissible value does move one: slab
  delta_ov = 1 admits mu_ov = 1, so the INTACT SLAB passes. Since {0,1} is the whole admissible
  set, the tolerance has exactly two settings: inert and vacuous. There is no third value,
  because any delta_ov in (0,1) is either state-dependent (P1-3) or arbitrary.
  => Phase 1's relaxation target exists, is unique, and CANNOT be used: raising it destroys
     the very discrimination the criterion lives on. Registered as PASS-WITH-NARROWING.

[P1-6] THE FEASIBLE WINDOW FOR CM5 ON THE CONVERTED STATE
  to CONVICT the converted state the estimator must resolve the interlayer spacing:
      Delta_z_res <= g_min = 8.620e-12 m
  to ACQUIT a real surface it must tolerate that surface's roughness:
      Delta_z_res > s_max * Delta_x
  together:  s_max * Delta_x < Delta_z_res <= g_min   =>  Delta_x < g_min / s_max
  roughness model              s_max        Delta_x <      verdict   
  atomic, corr. 1 nm           2.154e-01    4.002e-11      non-empty 
      at Delta_x = 1e-04 m the window is closed by a factor 2498839.9
  atomic, corr. 100 um         2.154e-06    4.002e-06      non-empty 
      at Delta_x = 1e-04 m the window is closed by a factor 25.0
  flat to 1 nm over 100 um     1.000e-05    8.620e-07      non-empty 
      at Delta_x = 1e-04 m the window is closed by a factor 116.0
  at the S0 sampling scale (100 um) the window is CLOSED for every roughness model above:
  atomic roughness over a 1 nm correlation length gives s_max*Delta_x = 2498839.91 x g_min.
  so a single (Delta_x, Delta_z_res) pair cannot both see the layering and tolerate the
  roughness. CM5 is therefore informative only for a surface flat below g_min/Delta_x, which
  is 8.62e-08 for the S0 scale -- i.e. flat to 8.6e-12 m over 100 um.
